# illumio-tui Plan 2: Interactive TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the btop-style interactive terminal UI on top of the finished `pce` library and CLI: four screens (Traffic with three views, Policy, Labels & objects, Workloads), a command prompt, help overlay, filter editor, opt-in auto-refresh, and profile switching, all read-only and PCE-friendly.

**Architecture:** Elm-style inside `crates/illumio-tui/src/tui/`: one `Model`, one `Msg` enum, a pure `update(&mut Model, Msg) -> Vec<Cmd>`, pure `view(&Model, &mut Frame)` functions, and one runtime (`app.rs`) that owns the terminal, the crossterm event stream, a `tokio::mpsc` channel for task results, and executes `Cmd`s by spawning tasks on a shared `Arc<Pce>`. Nothing in `tui/` performs I/O except `app.rs`. Screens are projections of `Model`; every data fetch is a `Cmd` caused by a user action or an opt-in refresh timer.

**Tech Stack:** ratatui 0.30 (default features, crossterm backend), crossterm 0.29 with `event-stream`, tokio 1, futures 0.3 (`StreamExt`), tokio-util `CancellationToken`, insta 1 (snapshots over `ratatui::backend::TestBackend`), the existing `pce` crate and `config.rs`.

**Spec:** `docs/superpowers/specs/2026-10-10-illumio-tui-design.md` — sections 3.2, 4, 5.2, 5.3, 5.4, 8 (items 3 and 4). Plan 1 (`docs/superpowers/plans/2026-10-10-pce-library-and-cli.md`) is merged on `main`; this plan builds only on its real interfaces (listed per task).

## Global Constraints

- Rust edition 2024, `rust-version = "1.88"`; `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and `cargo test --workspace` green at every commit. Clippy demands let-chains for nested `if`; list such collapses as deviations in reports.
- No I/O outside `crates/illumio-tui/src/tui/app.rs` and `main.rs` within the `tui` module: `update` and `view` are pure and must be testable with no terminal and no network.
- No unsolicited requests (spec 5.2): nothing refreshes on its own. Startup performs exactly: `GET /api/v2/health`, then the four object lists via `Pce::name_index` (one request each). Auto-refresh is opt-in per screen with `a`, minimum interval `config.auto_refresh_min_seconds` (already floored at 60), shows a countdown in the panel title, and skips a tick while a query is running or the terminal is unfocused.
- One traffic query at a time; editing the filter cancels the in-flight one (`CancellationToken`). View switches, sorting, searching, grouping, drill-downs never re-query. Truncation is always visible.
- Explorer defaults from the profile: window `traffic_default_window` (default `24h`), cap `traffic_max_results` (default 1000). The filter editor shows a cost hint and requires confirmation when `TrafficQuery::needs_confirmation()` returns `Some`.
- Rendering on demand: redraw after each `Msg`; a 250 ms tick runs only while a task is in flight. Idle UI must not spin.
- Cache TTLs and keys are the library's (`Pce` facade); the TUI shows cache age from `Cached::age` in panel titles and uses `CacheMode::Bypass` only for an explicit `r`.
- Key map (spec 4): screens `1`–`4`; `:` command prompt with `:traffic`, `:policy`, `:objects`, `:workloads`, `:filter <expr>`, `:window <dur>`, `:profile <name>`, `:draft`, `:active`, `:q`; `?` help; `q` quit (and `Ctrl-C`); Traffic: `v` cycle views, `f` edit filter, `r` run, `a` auto-refresh, `s` sort, `/` search, `g` group keys, `enter` drill-down/detail; Policy: `d` draft/active, `enter` detail, `p` pending; Objects: tab/shift-tab between object tabs, `r` refresh that type; Workloads: `t`/`T` jump to Traffic with the workload as source/destination.
- Look (spec 2): btop lineage: boxed panels with titled rounded borders, dense stats, bars and sparklines, one dark and one light palette selected by `--theme dark|light` (global flag; default dark; env `ILLUMIO_TUI_THEME`). Snapshots at 80×24 and 160×48 for both themes.
- Terminal hygiene: raw mode and alternate screen always restored, including on panic (panic hook) and on error exit. Mouse capture on (panel focus and scroll only).
- Secrets never rendered; the header shows host and org only.
- Commit trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

Inputs the spec implies but no task's tests would otherwise exercise; each has a pinned test in the owning task:

1. A terminal smaller than the layout minimum (e.g. 40×10) must render a "terminal too small" notice, never panic on zero-size `Rect`s (Task 2).
2. A key press while a query is in flight (view switch, sort, search) must be handled from the cached result without issuing a request, and `r` while running must be a no-op rather than a second query (Task 7).
3. Startup against an unreachable or unauthorised PCE must open the UI in a disconnected state with the error visible and let the user `:profile` to another profile or `q` (Task 3, Task 14).
4. A flow with no workload on either side (IP list to IP), no port (ICMP), or an unknown label href must render in every view without blank rows or panics (Task 8, Task 9).
5. Auto-refresh must never fire while a query is running, while unfocused, or before the minimum interval, and must cancel cleanly when the user disables it or switches profile (Task 10).
6. The command prompt must reject unknown commands and malformed arguments with a status-line error instead of silently doing nothing (Task 5).

```rust
// crates/illumio-tui/src/tui/model.rs
//! All TUI state. No I/O, no terminal types beyond sizes.
use crate::tui::ui::theme::Theme;
use pce::StatsSnapshot;
use std::time::Instant;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Screen {
    Traffic,
    Policy,
    Objects,
    Workloads,
}

impl Screen {
    pub const ALL: [Screen; 4] = [Screen::Traffic, Screen::Policy, Screen::Objects, Screen::Workloads];

    pub fn title(self) -> &'static str {
        match self {
            Screen::Traffic => "Traffic",
            Screen::Policy => "Policy",
            Screen::Objects => "Labels & objects",
            Screen::Workloads => "Workloads",
        }
    }

    pub fn index(self) -> usize {
        Screen::ALL.iter().position(|s| *s == self).unwrap_or(0)
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ProfileInfo {
    pub name: String,
    pub host: String,
    pub org_id: u64,
}

#[derive(Debug)]
pub enum Connection {
    Connecting,
    /// Health passed; the name index may still be loading (`index` None).
    Connected { index: Option<std::sync::Arc<pce::NameIndex>>, index_age_secs: u64 },
    Disconnected { error: String },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StatusKind {
    Info,
    Warn,
    Error,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StatusLine {
    pub text: String,
    pub kind: StatusKind,
}

impl StatusLine {
    pub fn info(text: impl Into<String>) -> Self {
        Self { text: text.into(), kind: StatusKind::Info }
    }
    pub fn warn(text: impl Into<String>) -> Self {
        Self { text: text.into(), kind: StatusKind::Warn }
    }
    pub fn error(text: impl Into<String>) -> Self {
        Self { text: text.into(), kind: StatusKind::Error }
    }
}

/// Limits copied from the resolved profile so `update` never touches config.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Limits {
    pub auto_refresh_min_seconds: u64,
    pub traffic_max_results: u32,
    pub traffic_default_window: String,
}

#[derive(Debug)]
pub struct Model {
    pub profile: ProfileInfo,
    pub theme_name: String,
    pub theme: Theme,
    pub limits: Limits,
    pub screen: Screen,
    pub connection: Connection,
    pub stats: StatsSnapshot,
    pub size: (u16, u16),
    pub focused: bool,
    pub status: StatusLine,
    /// Number of background tasks in flight; the runtime ticks at 250 ms while > 0.
    pub busy: usize,
    pub quit: bool,
    pub started: Instant,
}

impl Model {
    pub fn new_connecting(profile: ProfileInfo, theme_name: String, auto_refresh_min_seconds: u64, traffic_max_results: u32, traffic_default_window: String) -> Self {
        let theme = Theme::from_name(&theme_name);
        Self {
            profile,
            theme_name,
            theme,
            limits: Limits { auto_refresh_min_seconds, traffic_max_results, traffic_default_window },
            screen: Screen::Traffic,
            connection: Connection::Connecting,
            stats: StatsSnapshot { calls: 0, bytes: 0 },
            size: (80, 24),
            focused: true,
            status: StatusLine::info("connecting…"),
            busy: 0,
            quit: false,
            started: Instant::now(),
        }
    }

    pub fn set_theme(&mut self, name: &str) {
        self.theme_name = name.to_string();
        self.theme = Theme::from_name(name);
    }

    pub fn index(&self) -> Option<&std::sync::Arc<pce::NameIndex>> {
        match &self.connection {
            Connection::Connected { index, .. } => index.as_ref(),
            _ => None,
        }
    }

    pub fn is_connected(&self) -> bool {
        matches!(self.connection, Connection::Connected { .. })
    }
}
```

```rust
use crate::tui::model::Screen;
use crossterm::event::{KeyEvent, MouseEvent};
```

```rust
// crates/illumio-tui/src/tui/update.rs
//! Pure state transitions. Never performs I/O; returns `Cmd`s instead.
use crate::tui::model::{Connection, Model, Screen, StatusLine};
use crate::tui::msg::{Cmd, Msg};
use crossterm::event::{KeyCode, KeyEvent, KeyEventKind, KeyModifiers};
use pce::CacheMode;

pub fn update(model: &mut Model, msg: Msg) -> Vec<Cmd> {
    match msg {
        Msg::Key(k) => on_key(model, k),
        Msg::Mouse(_) => Vec::new(),
        Msg::Resize(w, h) => {
            model.size = (w, h);
            Vec::new()
        }
        Msg::Tick(_) => Vec::new(),
        Msg::Focus(f) => {
            model.focused = f;
            Vec::new()
        }
        Msg::Connected => {
            model.connection = Connection::Connected { index: None, index_age_secs: 0 };
            model.status = StatusLine::info("connected; loading labels, label groups, IP lists, services");
            vec![Cmd::LoadIndex(CacheMode::Use)]
        }
        Msg::ConnectFailed(e) => {
            model.status = StatusLine::error(format!("not connected: {e}"));
            model.connection = Connection::Disconnected { error: e };
            Vec::new()
        }
        Msg::IndexLoaded { index, age_secs } => {
            model.connection = Connection::Connected { index: Some(index), index_age_secs: age_secs };
            model.status = StatusLine::info("ready");
            Vec::new()
        }
        Msg::IndexFailed(e) => {
            model.status = StatusLine::error(format!("could not load objects: {e}"));
            Vec::new()
        }
        Msg::Stats(s) => {
            model.stats = s;
            Vec::new()
        }
        Msg::SwitchScreen(s) => {
            model.screen = s;
            Vec::new()
        }
    }
}

fn on_key(model: &mut Model, k: KeyEvent) -> Vec<Cmd> {
    if k.kind == KeyEventKind::Release {
        return Vec::new();
    }
    match (k.code, k.modifiers) {
        (KeyCode::Char('c'), KeyModifiers::CONTROL) | (KeyCode::Char('q'), KeyModifiers::NONE) => {
            model.quit = true;
            vec![Cmd::Quit]
        }
        (KeyCode::Char('1'), _) => switch(model, Screen::Traffic),
        (KeyCode::Char('2'), _) => switch(model, Screen::Policy),
        (KeyCode::Char('3'), _) => switch(model, Screen::Objects),
        (KeyCode::Char('4'), _) => switch(model, Screen::Workloads),
        _ => Vec::new(),
    }
}

fn switch(model: &mut Model, s: Screen) -> Vec<Cmd> {
    model.screen = s;
    Vec::new()
}
```

```rust
    let h = h.min(area.height);
    let x = area.x + (area.width - w) / 2;
    let y = area.y + (area.height - h) / 2;
```

```rust
// crates/illumio-tui/src/tui/app.rs
//! The runtime: the only I/O in `tui`. Owns the terminal, turns crossterm
//! events and task results into `Msg`s, runs `update`, draws, and executes
//! `Cmd`s by spawning tasks on a shared `Arc<Pce>`.
use crate::cli::error::CliError;
use crate::cli::{Context, GlobalArgs};
use crate::tui::model::{Model, ProfileInfo};
use crate::tui::msg::{Cmd, Msg};
use crate::tui::{update, view};
use crossterm::event::{DisableFocusChange, DisableMouseCapture, EnableFocusChange, EnableMouseCapture, Event, EventStream};
use futures::{Stream, StreamExt};
use pce::{CacheMode, Pce};
use std::sync::Arc;
use std::time::{Duration, Instant};
use tokio::sync::mpsc::{UnboundedReceiver, UnboundedSender, unbounded_channel};

pub const BUSY_TICK: Duration = Duration::from_millis(250);
pub const IDLE_TICK: Duration = Duration::from_secs(1);

pub struct Runtime {
    pub pce: Arc<Pce>,
    pub model: Model,
    tx: UnboundedSender<Msg>,
    rx: UnboundedReceiver<Msg>,
}

impl Runtime {
    pub fn new(pce: Arc<Pce>, model: Model) -> (Self, UnboundedSender<Msg>) {
        let (tx, rx) = unbounded_channel();
        (Self { pce, model, tx: tx.clone(), rx }, tx)
    }

    /// Executes one side effect. Tasks report back over the channel and
    /// always finish with `Msg::Stats` so the header counters stay current.
    pub fn execute(&mut self, cmd: Cmd) {
        match cmd {
            Cmd::Quit => self.model.quit = true,
            Cmd::Connect => {
                self.model.busy += 1;
                let (pce, tx) = (self.pce.clone(), self.tx.clone());
                tokio::spawn(async move {
                    let msg = match pce.health().await {
                        Ok(_) => Msg::Connected,
                        Err(e) => Msg::ConnectFailed(e.to_string()),
                    };
                    let _ = tx.send(msg);
                    let _ = tx.send(Msg::Stats(pce.stats()));
                });
            }
            Cmd::LoadIndex(mode) => {
                self.model.busy += 1;
                let (pce, tx) = (self.pce.clone(), self.tx.clone());
                tokio::spawn(async move {
                    let msg = match pce.name_index(mode).await {
                        Ok(index) => Msg::IndexLoaded { index, age_secs: 0 },
                        Err(e) => Msg::IndexFailed(e.to_string()),
                    };
                    let _ = tx.send(msg);
                    let _ = tx.send(Msg::Stats(pce.stats()));
                });
            }
        }
    }

    fn apply(&mut self, msg: Msg) {
        // A task result always lowers `busy`; terminal events do not.
        let task_result = matches!(msg, Msg::Connected | Msg::ConnectFailed(_) | Msg::IndexLoaded { .. } | Msg::IndexFailed(_));
        let cmds = update(&mut self.model, msg);
        if task_result {
            self.model.busy = self.model.busy.saturating_sub(1);
        }
        for c in cmds {
            self.execute(c);
        }
    }

    /// Tick period, or None when idle (no CPU use while nothing happens).
    pub fn tick_period(&self) -> Option<Duration> {
        if self.model.busy > 0 { Some(BUSY_TICK) } else { None }
    }
}

fn to_msg(e: Event) -> Option<Msg> {
    match e {
        Event::Key(k) => Some(Msg::Key(k)),
        Event::Mouse(m) => Some(Msg::Mouse(m)),
        Event::Resize(w, h) => Some(Msg::Resize(w, h)),
        Event::FocusGained => Some(Msg::Focus(true)),
        Event::FocusLost => Some(Msg::Focus(false)),
        Event::Paste(_) => None,
    }
}

/// Drives the model until `quit` or the event stream ends. `draw` is called
/// after every applied message batch. Generic over the event source so tests
/// can inject events.
pub async fn run_loop<S>(rt: &mut Runtime, mut events: S, draw: &mut dyn FnMut(&Model)) -> Model
where
    S: Stream<Item = Event> + Unpin,
{
    draw(&rt.model);
    loop {
        if rt.model.quit {
            break;
        }
        let tick = rt.tick_period();
        tokio::select! {
            ev = events.next() => match ev {
                Some(e) => { if let Some(m) = to_msg(e) { rt.apply(m); } }
                None => break,
            },
            Some(m) = rt.rx.recv() => rt.apply(m),
            _ = async { match tick { Some(d) => tokio::time::sleep(d).await, None => std::future::pending::<()>().await } } => {
                rt.apply(Msg::Tick(Instant::now()));
            }
        }
        // Drain whatever else is queued before drawing once.
        while let Ok(m) = rt.rx.try_recv() {
```

```rust
// crates/illumio-tui/src/tui/table.rs
//! Pure table state shared by every screen: rows, a search filter, a sort
//! column, a selection and a scroll offset. No rendering here.
#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord)]
pub enum SortKey {
    Text(String),
    Num(u64),
}

pub struct Column<T> {
    pub title: &'static str,
    /// Preferred width in cells; 0 means "take the remaining space".
    pub width: u16,
    pub cell: fn(&T) -> String,
    pub key: fn(&T) -> SortKey,
    pub right: bool,
}

impl<T> Clone for Column<T> {
    fn clone(&self) -> Self {
        Self { title: self.title, width: self.width, cell: self.cell, key: self.key, right: self.right }
    }
}

impl<T> std::fmt::Debug for Column<T> {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("Column").field("title", &self.title).field("width", &self.width).finish()
    }
}

#[derive(Debug)]
pub struct TableView<T> {
    pub columns: Vec<Column<T>>,
    rows: Vec<T>,
    visible: Vec<usize>,
    selected: usize,
    offset: usize,
    sort: Option<(usize, bool)>,
    search: String,
    searching: bool,
    search_draft: String,
}

impl<T> TableView<T> {
    pub fn new(columns: Vec<Column<T>>) -> Self {
        Self { columns, rows: Vec::new(), visible: Vec::new(), selected: 0, offset: 0, sort: None, search: String::new(), searching: false, search_draft: String::new() }
    }

    pub fn set_rows(&mut self, rows: Vec<T>) {
        self.rows = rows;
        self.apply();
    }

    pub fn rows(&self) -> &[T] {
        &self.rows
    }

    pub fn len(&self) -> usize {
        self.visible.len()
    }

    pub fn is_empty(&self) -> bool {
        self.visible.is_empty()
    }

    pub fn visible(&self) -> &[usize] {
        &self.visible
    }

    pub fn offset(&self) -> usize {
        self.offset
    }

    pub fn selected_index(&self) -> Option<usize> {
        self.visible.get(self.selected).copied()
    }

    pub fn selected_pos(&self) -> usize {
        self.selected
    }

    pub fn selected_item(&self) -> Option<&T> {
        self.selected_index().map(|i| &self.rows[i])
    }

    pub fn select_next(&mut self) {
        if !self.visible.is_empty() {
            self.selected = (self.selected + 1).min(self.visible.len() - 1);
        }
    }

    pub fn select_prev(&mut self) {
        self.selected = self.selected.saturating_sub(1);
    }

    pub fn page_down(&mut self, n: usize) {
        if !self.visible.is_empty() {
            self.selected = (self.selected + n.max(1)).min(self.visible.len() - 1);
        }
    }

    pub fn page_up(&mut self, n: usize) {
        self.selected = self.selected.saturating_sub(n.max(1));
    }

    pub fn home(&mut self) {
        self.selected = 0;
    }

    pub fn end(&mut self) {
        self.selected = self.visible.len().saturating_sub(1);
    }

    pub fn sort(&self) -> Option<(usize, bool)> {
        self.sort
    }

    /// `s` cycles: col0 asc, col0 desc, col1 asc, … then unsorted.
    pub fn sort_next(&mut self) {
        self.sort = match self.sort {
            None => Some((0, false)),
            Some((c, false)) => Some((c, true)),
            Some((c, true)) if c + 1 < self.columns.len() => Some((c + 1, false)),
            Some(_) => None,
        };
        self.apply();
    }

    pub fn sort_by(&mut self, col: usize, desc: bool) {
        self.sort = (col < self.columns.len()).then_some((col, desc));
        self.apply();
    }

    pub fn start_search(&mut self) {
        self.searching = true;
        self.search_draft = self.search.clone();
    }

    pub fn is_searching(&self) -> bool {
        self.searching
    }

    pub fn search_text(&self) -> &str {
        if self.searching { &self.search_draft } else { &self.search }
    }

    pub fn search_push(&mut self, c: char) {
        self.search_draft.push(c);
        self.apply();
    }

    pub fn search_pop(&mut self) {
        self.search_draft.pop();
        self.apply();
    }

    pub fn search_commit(&mut self) {
        self.search = std::mem::take(&mut self.search_draft);
        self.searching = false;
        self.apply();
    }

    pub fn search_cancel(&mut self) {
        self.search_draft.clear();
        self.searching = false;
        self.apply();
    }

    pub fn search_clear(&mut self) {
        self.search.clear();
        self.search_draft.clear();
        self.searching = false;
        self.apply();
    }

    /// Moves the scroll offset so the selected row is inside `height` rows.
    pub fn ensure_visible(&mut self, height: usize) {
        let h = height.max(1);
        if self.selected < self.offset {
            self.offset = self.selected;
        } else if self.selected >= self.offset + h {
            self.offset = self.selected + 1 - h;
        }
        let max_offset = self.visible.len().saturating_sub(h);
        self.offset = self.offset.min(max_offset);
    }

    pub fn cell(&self, row: &T, col: usize) -> String {
        (self.columns[col].cell)(row)
    }

    fn apply(&mut self) {
        let needle = self.search_text().to_lowercase();
        let mut vis: Vec<usize> = (0..self.rows.len())
            .filter(|&i| needle.is_empty() || self.columns.iter().any(|c| (c.cell)(&self.rows[i]).to_lowercase().contains(&needle)))
            .collect();
        if let Some((col, desc)) = self.sort {
            let key = self.columns[col].key;
            vis.sort_by(|&a, &b| {
                let o = key(&self.rows[a]).cmp(&key(&self.rows[b]));
                if desc { o.reverse() } else { o }
            });
        }
        self.visible = vis;
        if self.visible.is_empty() {
            self.selected = 0;
            self.offset = 0;
        } else {
            self.selected = self.selected.min(self.visible.len() - 1);
        }
    }
}
```

```rust
// crates/illumio-tui/src/tui/ui/widgets/table.rs
//! Renders a `TableView` as a ratatui Table inside a panel block. Column
//! widths come from the column definitions; `width == 0` fills the rest.
use crate::tui::table::TableView;
use crate::tui::ui::theme::Theme;
use ratatui::Frame;
use ratatui::layout::{Constraint, Rect};
use ratatui::style::Style;
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Cell, Paragraph, Row, Table, TableState};

pub fn header_meta<T>(view: &TableView<T>) -> String {
    let mut parts = Vec::new();
    if let Some((c, desc)) = view.sort() {
        parts.push(format!("sort {} {}", view.columns[c].title, if desc { "↓" } else { "↑" }));
    }
    if view.is_searching() {
        parts.push(format!("/{}▏", view.search_text()));
    } else if !view.search_text().is_empty() {
        parts.push(format!("/{}", view.search_text()));
    }
    parts.join(" · ")
}

pub fn render<T>(f: &mut Frame, area: Rect, view: &TableView<T>, theme: &Theme, block: Block, row_style: &dyn Fn(&T) -> Style) {
    let inner = block.inner(area);
    f.render_widget(block, area);
    if inner.height == 0 || inner.width == 0 {
        return;
    }
    if view.is_empty() {
        let msg = if view.search_text().is_empty() { "no rows" } else { "no rows match the search" };
        f.render_widget(Paragraph::new(Line::from(Span::styled(msg, theme.dim_style()))), inner);
        return;
    }
    let widths: Vec<Constraint> = view.columns.iter().map(|c| if c.width == 0 { Constraint::Min(8) } else { Constraint::Length(c.width) }).collect();
    let header = Row::new(view.columns.iter().map(|c| Cell::from(c.title)).collect::<Vec<_>>()).style(theme.header_style());
    let height = inner.height.saturating_sub(1) as usize; // minus header row
    let start = view.offset().min(view.visible().len());
    let end = (start + height).min(view.visible().len());
    let rows: Vec<Row> = view.visible()[start..end]
        .iter()
        .map(|&i| {
            let item = &view.rows()[i];
            let cells: Vec<Cell> = view
                .columns
                .iter()
                .enumerate()
                .map(|(ci, c)| {
                    let text = view.cell(item, ci);
                    let text = if c.right { format!("{text:>w$}", w = c.width as usize) } else { text };
                    Cell::from(text)
                })
                .collect();
            Row::new(cells).style(row_style(item))
        })
        .collect();
    let table = Table::new(rows, widths).header(header).column_spacing(1).row_highlight_style(theme.selected_style()).highlight_symbol("▸ ");
    let mut state = TableState::default().with_offset(0).with_selected(Some(view.selected_pos().saturating_sub(start)));
    f.render_stateful_widget(table, inner, &mut state);
}
```

```rust
//! The `:` command language. Parsing only; `update` executes.
use crate::tui::model::Screen;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Command {
    Screen(Screen),
    Filter(String),
    Window(String),
    Profile(String),
    Draft,
    Active,
    Quit,
    Help,
}

pub fn parse(input: &str) -> Result<Command, String> {
    let s = input.trim();
    if s.is_empty() {
        return Err("empty command".into());
    }
    let (name, arg) = match s.split_once(char::is_whitespace) {
        Some((n, a)) => (n, a.trim()),
        None => (s, ""),
    };
    let no_arg = |cmd: Command| if arg.is_empty() { Ok(cmd) } else { Err(format!(":{name} takes no argument")) };
    let with_arg = |f: fn(String) -> Command, usage: &str| if arg.is_empty() { Err(format!("usage: :{usage}")) } else { Ok(f(arg.to_string())) };
    match name {
        "traffic" | "t" => no_arg(Command::Screen(Screen::Traffic)),
        "policy" | "p" => no_arg(Command::Screen(Screen::Policy)),
        "objects" | "o" | "labels" => no_arg(Command::Screen(Screen::Objects)),
        "workloads" | "w" => no_arg(Command::Screen(Screen::Workloads)),
        "filter" | "f" => with_arg(Command::Filter, "filter <src expr>  (e.g. app=web,env=prod)"),
        "window" => with_arg(Command::Window, "window <duration>  (e.g. 1h, 24h, 7d)"),
        "profile" => with_arg(Command::Profile, "profile <name>"),
        "draft" => no_arg(Command::Draft),
        "active" => no_arg(Command::Active),
        "q" | "quit" => no_arg(Command::Quit),
        "help" | "h" | "?" => no_arg(Command::Help),
        other => Err(format!("unknown command :{other}; try :help")),
    }
}
```

```rust
                Vec::new()
```

```rust
// crates/illumio-tui/src/tui/filter.rs
//! The traffic filter as the user edits it (strings), its validation and
//! cost hints (no network), and its conversion to a `TrafficQuery` (needs
//! the name index, so it is async and runs in the runtime, not in `update`).
use pce::models::{PolicyDecision, ServiceMatch, TrafficQuery, proto_number};
use pce::traffic::{CONFIRM_MAX_RESULTS, CONFIRM_WINDOW, FilterExpr, TrafficQueryBuilder, parse_window};
use pce::{CacheMode, Pce};
use std::time::Duration;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TrafficFilter {
    pub window: String,
    pub src: String,
    pub dst: String,
    pub service: String,
    pub decisions: Vec<PolicyDecision>,
    pub max_results: u32,
}

fn parse_groups(text: &str) -> Result<Vec<Vec<FilterExpr>>, String> {
    text.split('|')
        .map(str::trim)
        .filter(|g| !g.is_empty())
        .map(|g| g.split(',').map(str::trim).filter(|e| !e.is_empty()).map(|e| FilterExpr::parse(e).map_err(|err| err.to_string())).collect())
        .collect()
}

impl TrafficFilter {
    pub fn defaults(window: &str, max_results: u32) -> Self {
        Self { window: window.to_string(), src: String::new(), dst: String::new(), service: String::new(), decisions: PolicyDecision::ALL.to_vec(), max_results }
    }

    pub fn window_duration(&self) -> Result<Duration, String> {
        parse_window(&self.window).map_err(|e| format!("window: {e}"))
    }

    pub fn src_groups(&self) -> Result<Vec<Vec<FilterExpr>>, String> {
        parse_groups(&self.src).map_err(|e| format!("source: {e}"))
    }

    pub fn dst_groups(&self) -> Result<Vec<Vec<FilterExpr>>, String> {
        parse_groups(&self.dst).map_err(|e| format!("destination: {e}"))
    }

    /// `443/tcp`, `443`, `tcp`; empty means no service filter.
    pub fn service_match(&self) -> Result<Option<ServiceMatch>, String> {
        let s = self.service.trim();
        if s.is_empty() {
            return Ok(None);
        }
        let (port_s, proto_s) = match s.split_once('/') {
            Some((p, pr)) => (p.trim(), Some(pr.trim())),
            None => (s, None),
        };
        let mut m = ServiceMatch::default();
        if let Some(pr) = proto_s {
            m.proto = Some(proto_number(pr).ok_or_else(|| format!("service: unknown protocol {pr:?}"))?);
            m.port = Some(port_s.parse::<u16>().map_err(|_| format!("service: bad port {port_s:?}"))?);
        } else if let Ok(p) = port_s.parse::<u16>() {
            m.port = Some(p);
        } else if let Some(n) = proto_number(port_s) {
            m.proto = Some(n);
        } else {
            return Err(format!("service: use PORT, PROTO or PORT/PROTO, got {s:?}"));
        }
        Ok(Some(m))
    }

    pub fn validate(&self) -> Result<(), String> {
        self.window_duration()?;
        self.src_groups()?;
        self.dst_groups()?;
        self.service_match()?;
        if self.max_results == 0 {
            return Err("max results must be at least 1".into());
        }
        Ok(())
    }

    pub fn is_unbounded(&self) -> bool {
        self.src.trim().is_empty() && self.dst.trim().is_empty() && self.service.trim().is_empty()
    }

    pub fn cost_hint(&self) -> String {
        let mut s = format!("window {} · cap {}", self.window, self.max_results);
        if self.is_unbounded() {
            s.push_str(" · unbounded");
        }
        s
    }

    pub fn needs_confirmation(&self) -> Option<String> {
        let mut reasons = Vec::new();
        if let Ok(w) = self.window_duration()
            && w > CONFIRM_WINDOW
        {
            reasons.push(format!("window {} exceeds {}d", self.window, CONFIRM_WINDOW.as_secs() / 86400));
        }
        if self.max_results > CONFIRM_MAX_RESULTS {
            reasons.push(format!("cap {} exceeds {}", self.max_results, CONFIRM_MAX_RESULTS));
        }
        if reasons.is_empty() { None } else { Some(reasons.join("; ")) }
    }

    pub fn summary(&self) -> String {
        let or = |s: &str| if s.trim().is_empty() { "*".to_string() } else { s.trim().to_string() };
        let decision = if self.decisions.len() == PolicyDecision::ALL.len() || self.decisions.is_empty() {
            "all".to_string()
        } else {
            self.decisions.iter().map(|d| d.as_str()).collect::<Vec<_>>().join(",")
        };
        format!("window {}  src {}  dst {}  svc {}  decision {}", self.window, or(&self.src), or(&self.dst), or(&self.service), decision)
    }

    /// Resolves names through the facade's cached index and builds the query.
    pub async fn to_query(&self, pce: &Pce, mode: CacheMode) -> pce::Result<TrafficQuery> {
        let window = self.window_duration().map_err(pce::PceError::Invalid)?;
        let mut b = TrafficQueryBuilder::last(window)?;
        let src = self.src_groups().map_err(pce::PceError::Invalid)?;
        let dst = self.dst_groups().map_err(pce::PceError::Invalid)?;
        for g in pce.resolve_filter_groups(&src, mode).await? {
            b = b.source(g);
        }
        for g in pce.resolve_filter_groups(&dst, mode).await? {
            b = b.destination(g);
        }
        if let Some(m) = self.service_match().map_err(pce::PceError::Invalid)? {
            b = b.service(m);
        }
        b.decisions(self.decisions.clone()).max_results(self.max_results).build()
    }
}
```

```rust
#[derive(Debug)]
pub enum QueryState {
    Idle,
    Running { seq: u64, started: Instant, status: String, cancel: CancellationToken },
    Failed(String),
}

#[derive(Debug)]
pub struct TrafficData {
    pub flows: Vec<ResolvedFlow>,
    pub truncated: bool,
    pub matches_count: Option<u64>,
    pub elapsed: Duration,
    pub cache_hit: bool,
    pub fetched_at: Instant,
    pub filter: TrafficFilter,
}

#[derive(Debug)]
pub struct TrafficState {
    pub filter: TrafficFilter,
    pub query: QueryState,
    pub data: Option<TrafficData>,
    pub seq: u64,
}

impl TrafficState {
    pub fn new(window: &str, max_results: u32) -> Self {
        Self { filter: TrafficFilter::defaults(window, max_results), query: QueryState::Idle, data: None, seq: 0 }
    }

    pub fn is_running(&self) -> bool {
        matches!(self.query, QueryState::Running { .. })
    }

    /// Cancels a running query (if any) and returns the next sequence number.
    pub fn start_query(&mut self, now: Instant) -> (u64, CancellationToken) {
        if let QueryState::Running { cancel, .. } = &self.query {
            cancel.cancel();
        }
        self.seq += 1;
        let cancel = CancellationToken::new();
        self.query = QueryState::Running { seq: self.seq, started: now, status: "submitting".into(), cancel: cancel.clone() };
        (self.seq, cancel)
    }
}
```

```rust
// crates/illumio-tui/src/tui/ui/widgets/bars.rs
//! Small dense-stat widgets in the btop spirit: a stacked decision bar, a
//! sparkline data helper and relative ages.
use crate::tui::ui::theme::Theme;
use pce::traffic::ResolvedFlow;
use ratatui::style::Style;
use ratatui::text::{Line, Span};
use std::time::Duration;

pub fn age_text(age: Duration) -> String {
    let s = age.as_secs();
    if s < 60 {
        format!("{s}s ago")
    } else if s < 3600 {
        format!("{}m ago", s / 60)
    } else {
        format!("{}h ago", s / 3600)
    }
}

/// A `width`-cell bar split proportionally: allowed, potentially blocked, blocked.
pub fn decision_bar(allowed: u64, pot: u64, blocked: u64, width: usize, t: &Theme) -> Line<'static> {
    let total = allowed + pot + blocked;
    if total == 0 || width == 0 {
        return Line::from(Span::styled("░".repeat(width), t.dim_style()));
    }
    let w = width as u64;
    let mut a = (allowed * w / total) as usize;
    let mut p = (pot * w / total) as usize;
    let mut b = (blocked * w / total) as usize;
    // Give rounding leftovers to the largest non-zero segment so the bar fills.
    let mut rest = width.saturating_sub(a + p + b);
    for (count, seg) in [(allowed, &mut a), (pot, &mut p), (blocked, &mut b)] {
        if count > 0 && rest > 0 {
            *seg += rest;
            rest = 0;
        }
    }
    Line::from(vec![
        Span::styled("█".repeat(a), Style::new().fg(t.ok)),
        Span::styled("█".repeat(p), Style::new().fg(t.warn)),
        Span::styled("█".repeat(b), Style::new().fg(t.bad)),
    ])
}

/// Flow counts per time bucket by `last_detected`, oldest bucket first.
pub fn sparkline_buckets(flows: &[ResolvedFlow], buckets: usize) -> Vec<u64> {
    let n = buckets.max(1);
    let mut out = vec![0u64; n];
    let ts: Vec<i64> = flows.iter().filter_map(|f| f.last_detected.as_deref()).filter_map(|s| s.parse::<jiff::Timestamp>().ok()).map(|t| t.as_second()).collect();
    let (Some(&min), Some(&max)) = (ts.iter().min(), ts.iter().max()) else {
        return out;
    };
    let span = (max - min).max(1);
    for t in ts {
        let i = (((t - min) * (n as i64 - 1)) / span) as usize;
        out[i.min(n - 1)] += 1;
    }
    out
}
```

```rust
            KeyCode::Enter => table.search_commit(),

        KeyCode::Enter => model.traffic.show_detail = !model.traffic.show_detail,
```

```rust
#[derive(Debug, Clone)]
pub struct AutoRefresh {
    pub enabled: bool,
    pub interval: Duration,
    pub last_run: Option<Instant>,
}

impl AutoRefresh {
    pub fn new(min_seconds: u64) -> Self {
        Self { enabled: false, interval: Duration::from_secs(min_seconds.max(60)), last_run: None }
    }
    pub fn due(&self, now: Instant) -> bool {
        self.enabled && self.last_run.is_none_or(|l| now.saturating_duration_since(l) >= self.interval)

    pub fn remaining(&self, now: Instant) -> Duration {
        self.last_run.map(|l| self.interval.saturating_sub(now.saturating_duration_since(l))).unwrap_or(Duration::ZERO)
    }
}
```

```rust
#[derive(Debug)]
pub struct PolicyState {
    pub scope: PolicyScope,
    pub pane: PolicyPane,
    pub rulesets: TableView<RuleSetView>,
    pub rules: TableView<RuleView>,
    pub raw: Vec<RuleSet>,
    pub fallback_deny: std::collections::HashMap<String, Vec<DenyRule>>,
    pub loaded_at: Option<Instant>,
    pub age_secs: u64,
    pub loading: bool,
    pub pending: Option<Vec<PendingChange>>,
    pub auto: AutoRefresh,
}

impl PolicyState {
    pub fn new(min_refresh: u64) -> Self {
        Self { scope: PolicyScope::Draft, pane: PolicyPane::RuleSets, rulesets: TableView::new(ruleset_columns()), rules: TableView::new(rule_columns()), raw: Vec::new(), fallback_deny: Default::default(), loaded_at: None, age_secs: 0, loading: false, pending: None, auto: AutoRefresh::new(min_refresh) }
    }

    pub fn set_rule_sets(&mut self, raw: Vec<RuleSet>, idx: &NameIndex) {
        self.rulesets.set_rows(raw.iter().map(|rs| RuleSetView::from_rule_set(rs, idx)).collect());
        self.raw = raw;
        self.rebuild_rules(idx);
    }

    /// Rules of the selected ruleset: allow rules, then deny rules (inline or fetched fallback).
    pub fn rebuild_rules(&mut self, idx: &NameIndex) {
        let Some(view) = self.rulesets.selected_item() else {
            self.rules.set_rows(Vec::new());
            return;
        };
        let href = view.href.clone();
        let Some(rs) = self.raw.iter().find(|r| r.href == href) else {
            self.rules.set_rows(Vec::new());
            return;
        };
        let mut rows: Vec<RuleView> = rs.rules.iter().map(|r| RuleView::from_rule(r, idx)).collect();
        let deny: &[DenyRule] = if rs.deny_rules.is_empty() { self.fallback_deny.get(&href).map(Vec::as_slice).unwrap_or(&[]) } else { &rs.deny_rules };
        rows.extend(deny.iter().map(|d| RuleView::from_deny(d, idx)));
        self.rules.set_rows(rows);
    }

    pub fn selected_href(&self) -> Option<String> {
        self.rulesets.selected_item().map(|r| r.href.clone())
    }
}
```

```rust
    model.screen = s;
    match s {
        Screen::Policy if model.policy.loaded_at.is_none() && !model.policy.loading && model.is_connected() => load_rule_sets(model, CacheMode::Use),
        _ => Vec::new(),

fn load_rule_sets(model: &mut Model, mode: CacheMode) -> Vec<Cmd> {
    model.policy.loading = true;
    model.policy.auto.last_run = Some(Instant::now());
    vec![Cmd::LoadRuleSets { scope: model.policy.scope, mode }]

fn policy_key(model: &mut Model, k: KeyEvent) -> Vec<Cmd> {
    use crate::tui::model::PolicyPane;
    let page = traffic_page(model); // same chrome height; both panes share the body height
    let idx = model.index().cloned();
    match k.code {
        KeyCode::Char('d') => {
            model.policy.scope = if model.policy.scope == PolicyScope::Draft { PolicyScope::Active } else { PolicyScope::Draft };
            model.policy.loaded_at = None;
            return load_rule_sets(model, CacheMode::Use);
        }
        KeyCode::Char('r') => return load_rule_sets(model, CacheMode::Bypass),
        KeyCode::Char('p') => {
            model.status = StatusLine::info("loading pending changes");
            return vec![Cmd::LoadPending(CacheMode::Use)];
        }
        KeyCode::Char('a') => {
            let a = &mut model.policy.auto;
            a.enabled = !a.enabled;
            model.status = if a.enabled { StatusLine::info(format!("auto-refresh every {}s", a.interval.as_secs())) } else { StatusLine::info("auto-refresh off") };
            return Vec::new();
        }
        KeyCode::Tab | KeyCode::BackTab => {
            model.policy.pane = if model.policy.pane == PolicyPane::RuleSets { PolicyPane::Rules } else { PolicyPane::RuleSets };
            return Vec::new();
        }
        KeyCode::Enter if model.policy.pane == PolicyPane::Rules => {
            if let Some(r) = model.policy.rules.selected_item() {
                model.overlay = Overlay::RuleDetail(r.clone());
            }
            return Vec::new();
        }
        _ => {}
    }
    let moved = match model.policy.pane {
        PolicyPane::RuleSets => table_nav(&mut model.policy.rulesets, k.code, page),
        PolicyPane::Rules => table_nav(&mut model.policy.rules, k.code, page),
    };
    if moved && model.policy.pane == PolicyPane::RuleSets
        && let Some(idx) = idx
    {
        model.policy.rebuild_rules(&idx);
    }
    Vec::new()
}

/// Shared table navigation; returns true when the selection may have changed.
fn table_nav<T>(table: &mut crate::tui::table::TableView<T>, code: KeyCode, page: usize) -> bool {
    if table.is_searching() {
        match code {
            KeyCode::Esc => table.search_clear(),
            KeyCode::Enter => table.search_commit(),
            KeyCode::Backspace => table.search_pop(),
            KeyCode::Char(c) => table.search_push(c),
            _ => {}
        }
        table.ensure_visible(page);
        return true;
    }
    match code {
        KeyCode::Down | KeyCode::Char('j') => table.select_next(),
        KeyCode::Up | KeyCode::Char('k') => table.select_prev(),
        KeyCode::PageDown => table.page_down(page),
        KeyCode::PageUp => table.page_up(page),
        KeyCode::Home => table.home(),
        KeyCode::End => table.end(),
        KeyCode::Char('s') => table.sort_next(),
        KeyCode::Char('/') => table.start_search(),
        _ => return false,
    }
    table.ensure_visible(page);
    true
}
```

```rust
use crate::tui::model::{Model, PolicyPane};
use crate::tui::ui::widgets::bars::age_text;

use pce::RuleKind;
use ratatui::Frame;
use ratatui::layout::{Constraint, Layout, Rect};
use ratatui::style::Style;
use std::time::Duration;

pub fn table_rows(body: Rect) -> usize {
    body.height.saturating_sub(3) as usize
}

pub fn render_screen(model: &Model, f: &mut Frame, body: Rect) {
    let t = &model.theme;
    let p = &model.policy;
    let cols = Layout::horizontal([Constraint::Percentage(45), Constraint::Percentage(55)]).split(body);
    let mut meta = format!("{} · {}", p.scope.segment(), if p.loading { "loading…".to_string() } else { format!("{}", age_text(Duration::from_secs(p.age_secs) + p.loaded_at.map(|l| l.elapsed()).unwrap_or_default())) });
    if p.auto.enabled {
        meta.push_str(&format!(" · auto in {}s", p.auto.remaining(std::time::Instant::now()).as_secs()));
    }
    let sort_meta = header_meta(&p.rulesets);
    if !sort_meta.is_empty() {
        meta = format!("{sort_meta} · {meta}");
    }
    let theme = t.clone();
    render(f, cols[0], &p.rulesets, t, panel("Rulesets", &meta, t, p.pane == PolicyPane::RuleSets), &move |r| if r.enabled { Style::default() } else { theme.dim_style() });
    let title = p.rulesets.selected_item().map(|r| format!("Rules · {}", r.name)).unwrap_or_else(|| "Rules".into());
    let theme = t.clone();
    render(f, cols[1], &p.rules, t, panel(&title, &header_meta(&p.rules), t, p.pane == PolicyPane::Rules), &move |r| match r.kind {
        RuleKind::Allow => Style::default(),
        RuleKind::Deny => Style::new().fg(theme.warn),
        RuleKind::OverrideDeny => Style::new().fg(theme.bad),
    });
}
```

```rust
/// Which tab a click at column `x` on the tabs row hits (labels are joined by a one-cell divider).
pub fn tab_at(x: u16) -> Option<Screen> {
    let mut start = 0u16;
    for (i, label) in tab_labels().iter().enumerate() {
        let w = label.chars().count() as u16;
        if x >= start && x < start + w {
            return Some(Screen::ALL[i]);
        }
        start += w + 1;
    }
    None
}

pub fn tab_x(screen: Screen) -> u16 {
    let mut start = 0u16;
    for (i, label) in tab_labels().iter().enumerate() {
        if Screen::ALL[i] == screen {
            return start + 1;
        }
        start += label.chars().count() as u16 + 1;
    }
    0
}
```

```rust
    use crossterm::event::{MouseButton, MouseEventKind};
```
